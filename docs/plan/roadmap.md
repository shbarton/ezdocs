# Roadmap and Milestones

## Milestone 0: Planning (Now)
- Finalize product brief and requirements.
- Decide on commercial model and license.
- Confirm Nextra version support.

## Milestone 1: MVP Core (Weeks 1-2)
- Config loader + schema validation.
- Content parsing and indexing.
- Nextra output generation.
- CLI binaries and basic dev flow.

## Milestone 2: MVP Template (Weeks 3-4)
- `docs` template completed.
- `npm create ezdocs` generator.
- End-to-end demo project.

## Milestone 3: v1 Enhancements (Weeks 5-6)
- Asset processing (images).
- TypeScript export generation.
- Improved navigation logic.

## Milestone 4: v1 Release (Weeks 7-8)
- Test suite coverage.
- Docs site and marketing copy.
- Release automation.

## Ongoing
- Additional templates.
- Plugins or extensions.
- Performance improvements for large sites.
