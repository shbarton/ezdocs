# Planning Workspace

This directory houses the planning documents for EZ Docs. Use it as the source of truth for vision, requirements, technical specs, templates, delivery, and commercial decisions before building or coding.

## Structure

- `project-overview.md` – high-level vision, philosophy, and workflow.
- `contentkit-analysis.md` – detailed look at the existing ContentKit foundation.
- `npm-based-architecture.md` – notes on the simplified CLI + npm workflow.
- `implementation-plan.md` – rollout plan, phases, and timelines.
- `index.md` – navigation hub linking all planning artifacts.
- `product-brief.md` / `requirements.md` / `commercial-model.md` / `open-questions.md` – product/market requirements, licensing, and outstanding decisions.
- `architecture.md` / `cli-spec.md` / `config-schema.md` / `content-model.md` / `nextra-integration.md` / `templates.md` – core technical specs for the build.
- `quality-plan.md` / `release-plan.md` / `roadmap.md` – QA, release, and milestone plans.

## How to use

1. Start with `index.md` to familiarize yourself with the doc set.
2. Update or add files here before writing code to keep the product, tech, and delivery decisions aligned.
3. Keep this directory under version control; treat it as the single source of planning truth.
